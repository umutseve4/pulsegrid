# M0 Acceptance Gates

This file is the canonical M0 checklist. Issue #1 mirrors it for operational tracking. Other repository documents must link here rather than duplicate the checklist.

- [x] Public repository exists.
- [x] Product promise and explicit non-goals are documented.
- [x] MVP scope is documented.
- [x] Malformed-event and source-outage semantics are documented.
- [x] Replay and idempotency contract is documented.
- [x] Visual storyboard and accessibility states are documented.
- [x] Architecture decision record is reviewed against the product contract.
- [x] Hosted CI validates required files, local Markdown links, checklist uniqueness, formatting, and forbidden promotional claims.
- [x] PR-head documentation CI is green with authoritative GitHub evidence.
- [ ] M0 pull request is merged and post-merge `main` is verified.

M0 is complete only when all ten gates are checked and the final two gates cite authoritative GitHub run and merge evidence in issue #1.
