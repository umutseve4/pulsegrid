# Visual Storyboard

## Scene 1 — Cold start

A dark grid wakes node by node. No fake activity is shown. The source reports `CONNECTING`; metric cards use skeleton states.

## Scene 2 — Healthy flow

Cyan event particles enter the gateway, pass the violet contract membrane, and illuminate Bronze, Silver, Gold, and the serving edge. The topology and numeric counters describe the same state.

## Scene 3 — Malformed event

One event turns crimson at the contract boundary. Its trusted-path animation stops; a visible branch carries it to quarantine. Inspecting it reveals the failed rule and preserved payload metadata.

## Scene 4 — Source outage

The source beacon fades to amber, the last-success clock ages, freshness deteriorates, and the topology enters `DEGRADED`. If deterministic simulation is enabled, every simulated particle is visibly marked.

## Scene 5 — Repair and replay

A quarantined event is repaired through a bounded action. Its replay follows a distinct ultraviolet trail. Idempotency evidence appears before the Gold node returns to healthy.

## Scene 6 — Incident time machine

The user scrubs through detect, quarantine, diagnose, repair, replay, and recover. Each transition shows the metric values and evidence that existed at that moment.

## Accessibility states

- Reduced-motion mode replaces particle movement with directional pulses and counters.
- Every node is keyboard focusable.
- Color is never the only status indicator.
- Live updates use non-disruptive announcements.
